Media servers

Set up Plex, Jellyfin, or both. At least one is required.

Plex

Find your token: open any item in Plex Web → ⋯ → Get Info → View XML, and copy the X-Plex-Token value from the address bar.

Jellyfin

Create one in Jellyfin: Dashboard → API Keys → +.

Display

Comma-separated Plex/Jellyfin usernames. Leave blank to show everyone's movies.

These switch a source off for everyone. Each viewer can also hide sources and sections on their own device with the Sources button.

Sign-in
